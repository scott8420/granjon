## Option 1 — Bundle into your app as a GResource (recommended)

This embeds the icons directly in your application binary.
No system installation required. Icons are loaded at runtime via GTK.

### Step 1 — Copy files into your project

Copy `scalable/`, `16x16/`, and `gresource.xml` into your project,
or merge them into your existing `*.gresource.xml`.

### Step 2 — Compile the GResource bundle

**With CMake:**

```cmake
find_program(GLIB_COMPILE_RESOURCES glib-compile-resources REQUIRED)

add_custom_command(
  OUTPUT  ${CMAKE_CURRENT_BINARY_DIR}/icons.c
  COMMAND ${GLIB_COMPILE_RESOURCES}
          --target=${CMAKE_CURRENT_BINARY_DIR}/icons.c
          --generate-source
          ${CMAKE_CURRENT_SOURCE_DIR}/gresource.xml
  DEPENDS ${CMAKE_CURRENT_SOURCE_DIR}/gresource.xml
  WORKING_DIRECTORY ${CMAKE_CURRENT_SOURCE_DIR}
)

target_sources(MyApp PRIVATE ${CMAKE_CURRENT_BINARY_DIR}/icons.c)
```

**With Meson:**

```meson
icons_res = gnome.compile_resources(
  'icons',
  'gresource.xml',
  source_dir: meson.current_source_dir(),
)
executable('myapp', sources + icons_res, ...)
```

**Manually:**

```bash
glib-compile-resources --generate-source --target=icons.c gresource.xml
# Then compile icons.c into your build.
```

### Step 3 — Register the resource prefix at runtime

Call this once before your GTK application window is shown:

```c
/* C */
gtk_icon_theme_add_resource_path(
    gtk_icon_theme_get_for_display(gdk_display_get_default()),
    "/granjon.curvz/icons"
);
```

```cpp
// C++ / gtkmm
auto theme = Gtk::IconTheme::get_for_display(Gdk::Display::get_default());
theme->add_resource_path("/granjon.curvz/icons");
```

### Step 4 — Use the icons

```cpp
// gtkmm — by icon name (without -symbolic suffix; GTK appends it automatically)
auto image = Gtk::make_managed<Gtk::Image>();
image->set_from_icon_name("edit-copy");   // loads edit-copy-symbolic

// Or with explicit symbolic lookup:
image->set_from_icon_name("edit-copy-symbolic");
```

GTK recolours symbolic icons automatically to match the current theme's
foreground colour. No manual colour management is needed.

## Option 2 — Install system-wide as an icon theme

This makes the icons available to any application on the system.

```bash
# User install (no root required)
mkdir -p ~/.local/share/icons/granjon.curvz
cp -r scalable 16x16 24x24 32x32 48x48 64x64 128x128 256x256 index.theme \
    ~/.local/share/icons/granjon.curvz/
gtk-update-icon-cache ~/.local/share/icons/granjon.curvz

# System install (requires root)
sudo cp -r scalable 16x16 24x24 32x32 48x48 64x64 128x128 256x256 index.theme \
    /usr/share/icons/granjon.curvz/
sudo gtk-update-icon-cache /usr/share/icons/granjon.curvz
```

After installation, select `granjon.curvz` in your desktop's
appearance settings, or set it programmatically:

```bash
gsettings set org.gnome.desktop.interface icon-theme 'granjon.curvz'
```

## Icon naming

All icons follow the [Freedesktop Icon Naming Specification](https://specifications.freedesktop.org/icon-naming-spec/latest/).
Symbolic variants carry the `-symbolic` suffix and use `currentColor`
so they recolour automatically with the GTK theme.
