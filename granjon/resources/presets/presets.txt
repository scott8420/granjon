# Granjon new-font presets (M12). Compiled into the core (tools/embed.cpp);
# edit here, rebuild. One [section] per preset, in the chooser's order;
# [keys] is shared by every proportional preset.
#
# Units are font units at the preset's upm. Per preset:
#   name / blurb        what the chooser shows
#   upm ascender descender x_height cap_height overshoot
#   stem_v stem_h       lowercase stems: vertical (n's stem) and horizontal
#                       (the thickness at the top of an arch or a bowl)
#   cap_stem_v cap_stem_h   the same for capitals (a little heavier)
#   serif serif_t       serif length past the stem, and its thickness (0 = sans)
#   mono                every advance (0 = proportional)
#   space               the space's advance
#   charset             the coverage set (resources/charsets/<id>.txt)
#   glyph: NAME width left right
#                       a starter glyph: its drawn width (outside to outside)
#                       and its sidebearings (mono: centred, left / right unused)
#   guide: NAME y       a font-wide horizontal guide
